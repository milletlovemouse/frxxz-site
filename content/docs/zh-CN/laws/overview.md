# 法则体系总览

在灵界后期与仙界篇中，力量层级从灵力、法宝、神通逐渐上升到法则与大道。法则决定修士能否迈向太乙、大罗、道祖等高阶层次。

## 三千大道

仙界篇设定中，三千大道对应不同法则。每一种法则最终都可通向道祖境，但同一条大道通常只能有一位道祖占据其顶点。

常见法则包括：时间、空间、轮回、五行、雷、鬼魅/魂魄、傀儡、毁灭、乾土、混沌等。

## 法则与境界

| 阶段 | 法则表现 |
|---|---|
| 人界 | 法则概念较弱，主要表现为天地元气、灵气、神通、禁制 |
| 灵界 | 玄天之宝、真灵、界面法则开始显性化 |
| 仙界 | 法则成为修炼主线，决定金仙、太乙、大罗、道祖层级上限 |

## 法则实体字段

| 字段 | 说明 |
|---|---|
| 名称 | 法则常用名。 |
| 类型 | 至尊法则、普通法则、特殊大道或推断法则。 |
| 层级 | 灵界显化、仙界主线、道祖级等。 |
| 代表人物 | 韩立、古或今、轮回殿主、蟹道人等。 |
| 代表功法 | 真言化轮经、水衍四时诀、炼神术等。 |
| 代表法宝 | 掌天瓶、玄天斩灵剑、元合五极山等。 |
| 能力方向 | 时间停滞、跨界、轮回、毁灭、破邪等。 |
| 所属大道 | 三千大道或更高层混沌线索。 |
| 敌对/互补法则 | 时间与轮回、毁灭与防御、雷与幽冥等关系。 |
| 置信度 | 原著明确、资料整理、待复核分层。 |
