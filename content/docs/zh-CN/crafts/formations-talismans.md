# 阵法与符箓

阵法和符箓是低中阶修士弥补境界差距的重要手段，也是秘境、传送、封印和宗门防御的基础设施。

## 阵法作用

| 作用 | 场景 |
|---|---|
| 防御洞府 | 修士隐居、闭关、药园保护 |
| 困敌杀敌 | 战斗、秘境、宗门防线 |
| 隐匿灵气 | 洞府、禁地、灵草保护 |
| 传送跨域 | 古传送阵、临时传送阵 |
| 封印 | 古魔、真灵、秘境、禁制 |
| 辅助炼丹炼器 | 地火屋、丹房、器房 |
| 宗门护山 | 星宫天星大阵、宗门大阵 |

## 重要阵法与禁制

- **古传送阵**：韩立从天南前往乱星海的重要通道。
- **阴火大阵**：鬼灵门血祭法阵。
- **四煞阵**：越国七派抵御魔道的防守法阵。
- **天星大阵**：星宫护持乱星海核心阵法。
- **北斗两仪阵**：封印玄骨的荒岛阵法。
- **小须弥金刚阵/金刚困仙阵**：佛宗困阵，持久力强。
- **乾天伏凌阵**：仙界篇太岁仙府相关收获。

## 辛如音阵法传承

辛如音是韩立早期阵法线的重要人物，精通阵法，曾赠送韩立阵法器具，并编撰《法阵要诀》。韩立后来将其阵法典籍传给田琴儿，形成“辛如音 -> 韩立 -> 田琴儿”的阵法传承线。

## 符箓体系

符箓可用于攻击、防御、隐匿、传送、通信、辅助和判断誓言。

| 符箓 | 类型 | 用途 |
|---|---|---|
| 隐身符/遁形符 | 隐匿 | 低中阶隐身 |
| 火弹符/冰弹符 | 攻击 | 基础属性攻击 |
| 传音符 | 通信 | 修士间传讯 |
| 金刚符 | 防御 | 金属性护身 |
| 问心符 | 判断 | 判断是否说谎 |
| 融灵符 | 特殊 | 暂时联结两名修士灵气 |
| 降灵符 | 高阶 | 天符门相关，韩立曾送还炼制之法 |

## 阵符词条字段

| 字段 | 说明 |
|---|---|
| 用途 | 防御、困敌、传送、封印、通信、辅助炼丹炼器等。 |
| 属性 | 五行、雷、冰、佛门、魔道、空间或特殊禁制。 |
| 消耗材料 | 阵盘、阵旗、符纸、灵石、特殊材料等。 |
| 使用者 | 韩立、辛如音、田琴儿、宗门或秘境守护者。 |
| 出现事件 | 血色禁地、古传送阵、虚天殿、昆吾山、仙府等。 |
| 可重复使用 | 一次性符箓、可维护阵法、宗门长期大阵。 |
| 置信度 | 原著明确、公开资料整理、待复核。 |
