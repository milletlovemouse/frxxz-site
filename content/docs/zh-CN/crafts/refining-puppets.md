# 炼器与傀儡

炼器把材料转化为法器、法宝、灵宝、玄天之宝；傀儡术则把材料、神识、阵法和魂魄/分神结合为额外战力。韩立两者兼修，使其战斗体系更稳定。

## 炼器基础

炼器依赖修士境界与真火/丹火/婴火、材料品质、炼器典籍、阵纹禁制、本命温养时间。

## 炼器实例

- **青竹蜂云剑**：金雷竹、庚精等材料，本命飞剑。
- **神风舟**：墨蛟蛟鳍和尾部炼制。
- **三焰扇**：多种灵焰与珍稀材料炼成。
- **元合五极山**：五座奇山炼制的后天玄天之宝。
- **元婴后期傀儡**：韩立在人界大晋阶段协助大衍神君炼制。

## 傀儡术体系

傀儡术适合神识强大的修士。大衍神君凭残缺傀儡秘籍复兴傀儡术，并创造大衍诀，可操控大量傀儡，甚至制造元婴后期级傀儡。

| 傀儡 | 特点 |
|---|---|
| 巨猿傀儡 | 二级傀儡，攻击力相当筑基期修士 |
| 巨龟傀儡 | 远战防御型，可喷雷火之球 |
| 人虎妖傀儡 | 近战敏捷型，攻击强防御弱 |
| 青面獠牙恶鬼傀儡 | 元婴级傀儡，韩立炼制过 |
| 元婴后期傀儡 | 韩立协助大衍神君搜集材料后炼成 |
| 蟹道人 | 仙界高阶仙傀儡，具有自主智慧 |
