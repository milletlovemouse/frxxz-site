# 功法神通总览

凡人体系中的功法不是简单技能列表，而是角色成长路线、战斗风格、瓶颈处理和势力传承的综合载体。功法通常与灵根、境界、法宝、材料、修炼代价和创始势力绑定。

## 功法类型

| 类型 | 代表 | 作用 |
|---|---|---|
| 基础修炼功法 | 长春功 | 入门、炼气、低阶法术基础 |
| 主修功法 | 青元剑诀、真言化轮经 | 决定长期路线与核心战力 |
| 辅助功法 | 三转重元功 | 压缩真元、提高突破概率、承担代价 |
| 神识功法 | 大衍诀、炼神术 | 提升神识、分神、傀儡操控与高阶因果 |
| 炼体功法 | 明王诀、梵圣真魔功、百脉炼宝决 | 强化肉身，支撑高负荷法宝和玄天之宝 |
| 魔道秘术 | 玄阴经、黑煞修罗功、血影遁 | 强力但常伴随副作用和伦理风险 |
| 法则功法 | 真言门时间功法群 | 进入仙界大道层级的核心路径 |

## 韩立核心功法

- **长春功**：木属性基础功法，韩立早期修炼，共十三层，对应炼气期。
- **青元剑诀**：长期主修剑诀，配套青竹蜂云剑、大庚剑阵、春黎剑阵、青蟠剑阵。
- **三转重元功**：青元剑诀辅助功法，通过散功压缩真元增加结丹几率。
- **大衍诀**：大衍神君所创，强化神识与分神，服务傀儡操控。
- **梵圣真魔功**：综合佛门、魔功与妖族功法的法体双修路线。
- **百脉炼宝决**：金阙玉书外页记载，将身体部位炼为法宝。
- **真言化轮经**：真言门时间功法，仙界篇时间法则主线核心。
- **炼神术**：轮回殿主所创逆天神识功法，强大但限制极重。

## 功法实体字段

| 字段 | 说明 |
|---|---|
| 名称 | 功法、秘术或神通常用名。 |
| 类型 | 基础修炼、主修、辅助、神识、炼体、魔道、法则功法等。 |
| 属性 | 木、金、雷、冰、魔、佛、时间、空间等。 |
| 创始人 | 大衍神君、真言门祖师、轮回殿主等。 |
| 传承势力 | 黄枫谷、千竹教、真言门、轮回殿等。 |
| 适用境界 | 炼气至仙界不同阶段。 |
| 前置条件 | 灵根、境界、神识、肉身、材料或法宝要求。 |
| 配套法宝 | 青竹蜂云剑、掌天瓶、风雷翅等。 |
| 代表神通 | 剑阵、分神术、时间宝轮、炼体法相等。 |
| 修炼代价 | 散功、心魔、寿元、神识限制或法体负荷。 |
| 相关人物 | 韩立、大衍神君、古或今、轮回殿主等。 |
| 置信度 | 原著明确、资料整理、待复核。 |
