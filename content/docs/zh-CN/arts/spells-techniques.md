# 法术秘术与神通

法术和神通是功法的表现层。低阶法术用于入门与生存，高阶秘术则服务逃遁、控场、破邪、神魂攻击和法则应用。

## 基础法术

| 法术 | 属性/类型 | 用途 |
|---|---|---|
| 火弹术 | 火属性攻击 | 低阶攻击 |
| 御风诀 | 风/身法 | 移动与飞行辅助 |
| 控物术 | 操控 | 操控物品 |
| 天眼术 | 侦查 | 观察灵气、禁制等 |
| 地刺术/流沙术 | 土属性 | 控制与地形干扰 |
| 冰冻术 | 寒属性 | 冰冻控制 |
| 缠绕术 | 木属性 | 束缚控制 |
| 传音术 | 通信 | 短距离或特定条件通信 |
| 匿身术 | 隐匿 | 低阶隐匿手段 |

## 遁术

- **血影遁**：燃烧精血进行逃遁，代价较大。
- **疾风九变**：与风遁、身法、风雷翅相关。
- **雷遁**：风雷翅、辟邪神雷、雷阵相关。
- **金篆文传送阵**：高阶跨域传送相关。

## 神识与元神秘术

| 秘术 | 体系 | 说明 |
|---|---|---|
| 分神术 | 大衍诀 | 操控傀儡与多线作战基础 |
| 惊神刺 | 神识攻击 | 干扰或攻击敌方神识 |
| 梦引术 | 魔道神魂 | 搜索、改动神识类秘术 |
| 离魂术 | 元婴/神魂 | 影响元婴灵智 |
| 封魂咒 | 昆吾山等剧情 | 神魂封禁线索 |

## 剑阵与雷法

- **大庚剑阵**：青竹蜂云剑 + 庚精，剑丝无坚不摧。
- **春黎剑阵**：灵界新剑阵，以幻术与木性变化为核心。
- **青蟠剑阵**：更高阶青元剑诀剑阵。
- **辟邪神雷**：金雷竹相关，对魔气、阴邪具有强克制。
- **祭雷术**：地渊/木青传授线索，韩立掌握上半部。
- **叱念真雷**：韩立用于控制或威慑特定敌人的手段。
