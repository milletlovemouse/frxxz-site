# 来源与置信度

凡人知识库内容来自原著、公开百科、正版阅读平台章节目录和读者整理资料。为避免把二创设定混入正文，需要明确来源优先级和置信度。

## 来源优先级

1. 原著正文与起点章节目录/作品设定。
2. 百度百科词条：《凡人修仙传》《凡人修仙之仙界篇》《韩立》《玄天之宝》《混沌万灵榜》等。
3. 正版阅读平台章节目录：微信读书、得到等。
4. 起点评论区/凡人必备手册类读者整理资料。
5. 读者文章、B 站、知乎、搜狐、网易等二次整理：仅作线索，需复核。

## 置信度标准

| 等级 | 标准 | 展示方式 |
|---|---|---|
| 高 | 原著明确、多个可靠来源一致 | 可直接写入词条正文 |
| 中 | 公开资料一致，但暂未定位原文 | 标注“公开资料整理，待章节复核” |
| 低 | 读者推断、二创化设定、资料冲突 | 放入待复核区，不作为核心结论 |

## 内容治理规则

- 对境界、寿元、丹方、体质、法则等容易争议的设定优先标注来源。
- 对人物结局、仙界篇终局境界、灵宠最终归宿避免无来源断言。
- 对“游戏化数值”“完整丹方配比”“读者扩展解释”单独分层，不混入原著设定。
- 页面新增内容时优先补齐来源和置信度，而不是只扩写描述。

## 复核队列

- 仙界境界分层：人仙/地仙/天仙/真仙与主流真仙、金仙、太乙、大罗、道祖体系的关系。
- 寿元数值：多为读者整理或推算，应标注近似。
- 丹药材料：区分原著明确材料与二创丹方。
- 灵宠结局：部分角色结尾未明确交代，应避免绝对化。
