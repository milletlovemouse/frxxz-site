# 韩立成长线

韩立是《凡人修仙传》与《仙界篇》的主角，出身天南越国镜州青牛镇五里沟，家境贫寒，因进入七玄门被墨大夫收为弟子，修炼长春功而踏上修仙道路。

## 核心档案

## 七阶段成长

1. **凡人阶段**：青牛镇 -> 七玄门 -> 墨大夫夺舍阴谋 -> 获得神秘小瓶。
2. **入门修仙**：太南小会 -> 黄枫谷 -> 血色禁地 -> 筑基。
3. **天南动荡**：魔道入侵 -> 古传送阵 -> 乱星海。
4. **乱星海崛起**：猎妖、虚天殿、噬金虫、虚天鼎、结丹/元婴。
5. **重返天南/大晋**：落云宗、坠魔谷、昆吾山、小极宫、化神与空间节点。
6. **灵界篇**：天渊城、蛮荒任务、天鹏族、地渊、冥河之地、广寒界、魔界、大乘、飞升。
7. **仙界篇**：北寒仙域、烛龙道、真言门遗迹、灰界、魔域、时间法则、轮回殿、道祖之战。

## 逆袭逻辑

韩立的成长不是单靠“主角天赋”，而是多个系统长期叠加：

- **掌天瓶**解决灵草和丹药资源瓶颈。
- **炼丹能力**把资源转化为修为增长。
- **大衍诀**强化神识，使飞剑、傀儡、灵虫和斗法判断长期受益。
- **青竹蜂云剑**与剑阵体系提供稳定主战力。
- **炼体功法**让韩立能承受高阶法宝和玄天之宝负荷。
- **谨慎行事**使其在资源争夺中多次避开致命风险。
