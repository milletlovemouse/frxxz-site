# 实体模型

知识库以 Markdown 专题承载正文，同时使用统一实体模型组织结构化图谱信息。实体模型的目标是让每个词条可检索、可关联、可筛选、可复核。

## 通用字段

| 字段 | 说明 | 示例 |
|---|---|---|
| `id` | 稳定唯一标识 | `character_hanli` |
| `name` | 中文名称 | 韩立 |
| `aliases` | 别名 | 韩老魔、厉飞雨 |
| `category` | 实体类型 | 人物、地域、功法、法宝、丹药、阵法、法则 |
| `world_stage` | 所属阶段 | 人界篇、灵界篇、仙界篇 |
| `realm_level` | 关联境界或适用境界 | 元婴、化神、大乘、真仙 |
| `description` | 简介 | 一句话概括 |
| `details` | 详细说明 | Markdown/MDX 正文 |
| `relations` | 关系边 | 修炼、持有、所属、克制 |
| `sources` | 来源 | 章节、百科、公开资料、备注 |
| `confidence` | 置信度 | 高、中、低 |

## 分类字段补充

- 人物：所属势力、灵根/体质、境界、功法、法宝、灵兽、技艺、关系。
- 地域：界面、上级地域、主要势力、关键事件、资源产出、传送关系。
- 功法：属性、类型、创始人、传承势力、适用境界、前置条件、代价。
- 法宝：层级、持有人、材料、能力、克制对象、结局。
- 材料：稀有度、产地、用途、可炼制物、使用者。
- 法则：层级、代表人物、功法、法宝、能力方向。

## 稳定锚点原则

路径和锚点一旦被外部引用，应尽量保持稳定。中文显示名可以变化，但实体 ID 和 URL slug 应尽量不变。
