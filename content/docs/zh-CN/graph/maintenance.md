# 图谱维护策略

图谱维护的关键不是一次性写完，而是让知识库持续保持稳定路径、来源分层、关系可追溯和数据结构一致。

## 维护原则

- **稳定路径**：页面 URL 和实体 ID 尽量不改，显示标题可调整。
- **来源分层**：原著、官方/正版资料、百科、读者整理、推断内容分层展示。
- **置信度明确**：每条待争议设定标注高、中、低置信度。
- **关系可追溯**：每条关系边应能追溯到具体页面或来源。
- **长文拆专题**：避免继续把所有资料堆进单页，优先按实体和关系拆分。

## 数据化路线

| 步骤 | 内容 |
|---|---|
| 1 | 从 Markdown 页面整理实体 ID 和关系边。 |
| 2 | 建立 `entities` 与 `relations` 数据文件。 |
| 3 | 为人物、法宝、功法、材料、法则提供筛选入口。 |
| 4 | 将 Mermaid 图谱作为核心关系图展示。 |
| 5 | 为每个实体补充来源章节与置信度。 |

## 待复核重点

- 仙界境界的具体分层。
- 寿元数值与不同来源差异。
- 丹方材料配比是否原著明确。
- 灵宠最终结局与仙界篇角色归宿。
- 部分法则、体质、灵根变异表述是否来自读者扩展。
