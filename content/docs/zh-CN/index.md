# 凡人修仙传知识库

本知识库不再按原始资料长文堆叠，而是把《凡人修仙传》与《凡人修仙之仙界篇》的设定拆成可持续维护的专题：世界、修炼、人物、功法、器物、百艺、灵兽、法则与知识图谱。

## 推荐阅读路径

1. 从 [世界观总览](/docs/world/overview) 建立“三界与资源稀缺”的底层认知。
2. 阅读 [灵根与资质](/docs/cultivation/spiritual-roots) 与 [境界阶梯](/docs/cultivation/realms)，理解韩立为什么需要资源与机缘。
3. 进入 [韩立成长线](/docs/characters/han-li)，把地域、势力、功法、法宝与人物关系串起来。
4. 通过 [功法成长树](/docs/arts/han-li-growth-tree)、[掌天瓶](/docs/treasures/palm-bottle)、[核心关系图谱](/docs/graph/core-relations) 追踪关键设定之间的因果。

## 内容分区

- [世界观](/docs/world/overview)：界面层级、人界地域、灵界族群、仙界势力与宗门地图。
- [修炼体系](/docs/cultivation/spiritual-roots)：灵根、体质、境界、天劫、寿元、夺舍与资源瓶颈。
- [人物图谱](/docs/characters/han-li)：韩立主线、道侣红颜、师友盟友、敌手与势力首领。
- [功法神通](/docs/arts/overview)：基础功法、剑诀、炼体、神识、遁术、雷法与仙界法则功法。
- [器物资源](/docs/treasures/artifact-levels)：法器、法宝、通天灵宝、玄天之宝、掌天瓶与材料。
- [修仙百艺](/docs/crafts/alchemy)：炼丹、炼器、阵法、符箓、傀儡、御兽与虫修。
- [灵兽妖兽](/docs/beasts/companions)：韩立灵宠伙伴、真灵体系、傀儡与灵虫成长线。
- [法则大道](/docs/laws/overview)：时间、空间、轮回、混沌与其他法则。
- [知识图谱](/docs/graph/entity-model)：实体字段、关系边、稳定锚点与维护策略。
- [资料治理](/docs/governance/sources-confidence)：来源优先级、置信度和待复核项。
