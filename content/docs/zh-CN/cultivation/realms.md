# 境界阶梯

境界是凡人世界最重要的硬规则之一。高阶修士通常在法力、神识、寿元、肉身、法宝催动与天地元气调动上全面压制低阶修士。

## 人界与灵界主体系

| 阶段 | 境界 | 常见分期 | 核心特征 |
|---|---|---|---|
| 下境界 | 炼气期 | 约十三层 | 吸纳灵气，施展基础法术，使用低阶法器/符箓 |
| 下境界 | 筑基期 | 初/中/后/大圆满 | 真元液化，正式跨入修仙门槛，寿元约二百年 |
| 下境界 | 结丹期/金丹期 | 初/中/后/大圆满 | 凝结金丹，可炼制本命法宝，寿元约四五百年 |
| 下境界 | 元婴期 | 初/中/后/大圆满 | 丹破婴生，元婴可离体，夺舍与婴火体系出现 |
| 下境界 | 化神期 | 初/中/后/大圆满 | 可初步调动天地元气，人界巅峰，寻找飞升路径 |
| 中境界 | 炼虚期 | 初/中/后/大圆满 | 飞升灵界后的高阶阶段，五行合一与天地灵气运用增强 |
| 中境界 | 合体期 | 初/中/后/大圆满 | 元神肉身融合深化，法体与神通大成 |
| 中境界 | 大乘期 | 初/中/后/大圆满 | 灵界顶级强者，面对大天劫与飞升资格 |
| 上境界 | 渡劫/飞升 | 特殊阶段 | 渡飞升之劫，进入仙界 |

> 部分资料将“渡劫期”作为大乘后的独立阶段，部分将其视为飞升前关口。此处保留差异，并按资料层级处理。

## 仙界篇主体系

| 境界 | 核心说明 |
|---|---|
| 真仙 | 飞升仙界后的基础仙人层级之一，开始接触仙灵力、仙窍、衰劫等体系 |
| 金仙 | 法则领悟与仙窍积累增强 |
| 太乙 | 高阶仙人，灵域与法则运用更加成熟 |
| 大罗 | 接近大道巅峰，法则掌控极深 |
| 道祖 | 一条大道/法则的顶点，三千大道对应道祖格局 |

部分资料还提到人仙、地仙、天仙、玄仙等层次，不同来源表述不一，当前作为待复核层级，不并入主境界表。

## 妖兽等级对应

| 妖兽等级 | 大致对应修士 | 特征 |
|---|---|---|
| 1-3级 | 炼气至筑基中期 | 灵智较低，基础妖兽/灵兽 |
| 4-6级 | 筑基后期至结丹中期 | 初具妖丹，战力明显提升 |
| 7-8级 | 结丹后期至元婴初期 | 可半化形或具高阶神通 |
| 9-10级 | 元婴中后期 | 化形完整，灵智成熟 |
| 11-13级 | 化神至合体 | 高阶妖修/灵兽，常具空间等强大神通 |
| 真灵级 | 大乘至真仙级别 | 真龙、天凤、罗睺、游天鲲鹏等 |

## 境界词条字段

| 字段 | 说明 |
|---|---|
| 适用篇章 | 人界、灵界、仙界或跨篇章阶段。 |
| 常见分期 | 初期、中期、后期、大圆满等内部层级。 |
| 寿元近似 | 常见整理值，仅作为阅读参考。 |
| 标志能力 | 法力、神识、肉身、法宝催动或天地元气调动变化。 |
| 突破瓶颈 | 丹药、天劫、心魔、资源或功法限制。 |
| 代表人物 | 可帮助定位该境界战力和剧情阶段的人物。 |
| 关联资源 | 常用丹药、典型法宝、灵地与常见劫难。 |
| 置信度 | 区分原著明确、资料整理与存在冲突的说法。 |
