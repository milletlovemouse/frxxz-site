# 真灵体系

真灵是超越普通妖兽的顶级存在，常可与真仙抗衡，血脉与法则神通强大。灵界篇中，真灵血脉与族群传承直接影响韩立的炼体、遁术和高阶战斗。

## 已知真灵与族群

| 真灵 | 属性/特征 | 关联线索 |
|---|---|---|
| 真龙 | 龙族血脉，强大肉身与法则神通 | 真龙真血、梵圣真魔功、涅槃圣体 |
| 天凤 | 凤族血脉，飞遁与火/风属性线索 | 天凤之翎、风雷翅进阶 |
| 游天鲲鹏 | 风属性真灵，体型巨大 | 惊蛰诀、天鹏族、鲲鹏舍利 |
| 罗睺 | 吞食日月、穿梭界面 | 与鲲鹏宿敌，混沌魔兽级存在 |
| 五色孔雀/五光孔雀 | 五色神光与真血 | 惊蛰诀、真灵变化 |
| 山岳巨猿 | 巨力与法相 | 韩立法相/变身体系 |
| 麒麟 | 墨麒麟、离火麒麟等 | 豹麟兽血脉线索 |
| 天狐/九尾仙狐 | 幻术、魅惑、妖族血脉 | 银月/玲珑相关妖族体系 |

## 真灵血脉作用

- 强化肉身。
- 赋予变化神通。
- 增强遁速、属性神通和战斗爆发。
- 与惊蛰诀、梵圣真魔功、涅槃圣体等配合。
- 影响族群身份、试炼资格和资源争夺。
