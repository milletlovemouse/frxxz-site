# 傀儡与虫修

傀儡和虫修都属于“以外部战力弥补自身限制”的体系。前者依赖材料、阵法和神识，后者依赖培养、繁殖、筛选和控制。

## 傀儡术

大衍神君是傀儡体系核心人物，千竹教是重要传承势力。大衍诀增强神识与分神能力，使韩立能操控傀儡、飞剑、灵虫等多线战力。

| 傀儡 | 战力/特征 | 关联 |
|---|---|---|
| 巨猿傀儡 | 二级傀儡，攻击力相当筑基期修士 | 铁木材料 |
| 巨龟傀儡 | 防御型，远战雷火攻击 | 傀儡真经 |
| 人虎妖傀儡 | 近战敏捷型 | 攻强防弱 |
| 青面獠牙恶鬼傀儡 | 元婴级 | 韩立炼制 |
| 元婴后期傀儡 | 高阶傀儡 | 韩立协助大衍神君炼成 |
| 蟹道人 | 仙傀儡 | 傀儡法则、空间/雷法线索 |

## 虫修体系

噬金虫是虫修线核心。其培养从虫卵、虫群、成熟体到虫王筛选，体现“数量 + 吞噬 + 进化”的路线。

| 灵虫 | 能力 | 说明 |
|---|---|---|
| 噬金虫 | 吞食五金与天地灵气，破法宝 | 韩立长期底牌 |
| 噬金虫王 | 通过互相吞噬筛选而成 | 高阶灵智与恐怖战力 |
| 金童 | 虫王化形/仙界因果 | 仙界篇重要角色 |
| 六翼霜蚣 | 冰属性、遁速、真龙血脉 | 培养难，后期有反叛线 |

## 虫修实体字段

| 字段 | 说明 |
|---|---|
| 培养方式 | 繁殖、吞噬、筛选、秘术培养或丹药辅助。 |
| 食物/材料 | 五金、灵气、特殊材料或同类吞噬资源。 |
| 控制方式 | 神识控制、契约、法器辅助或虫王统御。 |
| 进化阶段 | 虫卵、成熟体、虫群、虫王、化形个体。 |
| 克制对象 | 法宝、护体灵光、低阶修士或特定属性神通。 |
| 战斗方式 | 群攻、吞噬、破防、追踪、近身压制。 |
| 化形状态 | 未化形、虫王化形、独立智慧。 |
| 最终状态 | 留在韩立体系、独立行动或进入仙界因果。 |
