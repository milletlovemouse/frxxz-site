# 材料与资源

材料是连接炼丹、炼器、法宝、灵兽培养和境界突破的关键实体。本页按材料用途、关联物品、产地线索、使用者、稀有度和来源置信度组织。

## 材料实体字段

| 字段 | 说明 |
|---|---|
| `name` | 材料名称。 |
| `category` | 炼器材料、灵草灵药、丹药材料、阵法材料等。 |
| `rarity` | 常见、稀有、高阶、玄天/仙界级等。 |
| `world_stage` | 人界、灵界、仙界或跨篇章。 |
| `origin` | 产地、秘境、妖兽来源或交易渠道。 |
| `used_for` | 炼丹、炼器、培养灵兽、突破境界等用途。 |
| `related_items` | 可炼制或关联的丹药、法宝、阵法。 |
| `related_characters` | 使用者、持有者或争夺者。 |
| `source` | 原著、公开资料或读者整理来源。 |
| `confidence` | 高、中、低置信度。 |

对网络上常见的“完整丹方配比”应谨慎处理，明确区分原著明确材料和二创/游戏化设定。
