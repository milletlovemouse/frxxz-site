# 器物等级

《凡人修仙传》的器物体系会随篇章升级：人界重法器、法宝、通天灵宝；灵界突出玄天之宝与混沌万灵榜；仙界则进入仙器、道器和法则器物层面。

## 等级概览

| 层级 | 使用阶段 | 特点 | 代表 |
|---|---|---|---|
| 普通兵器 | 凡人/极低阶 | 不依赖法力 | 江湖兵器 |
| 法器 | 炼气/筑基 | 消耗法力较少，威力低于法宝 | 金蚨子母刃、精钢环、青蛟旗、神风舟 |
| 符宝 | 低中阶过渡 | 将法宝部分威能封入符箓，使用次数有限 | 飞剑符宝、金光砖符宝 |
| 法宝 | 结丹期后 | 可祭炼，本命法宝可随修士成长 | 青竹蜂云剑、风雷翅、三焰扇 |
| 古宝/特殊宝物 | 中高阶 | 来历特殊，常具强力禁制或传承 | 鬼罗幡、乾蓝鼎、逆星盘、金阙玉书 |
| 通天灵宝 | 人界/灵界高阶 | 威能远超普通法宝 | 虚天鼎、八灵尺 |
| 玄天之宝 | 灵界顶层 | 蕴含法则，常引发界面争夺 | 玄天斩灵剑、元合五极山、玄天葫芦 |
| 仙器/道器 | 仙界 | 与仙灵力、法则、道祖格局相关 | 仙界篇高阶器物 |

## 关键法宝

- **青竹蜂云剑**：韩立本命法宝，以金雷竹炼制，后加入庚精、玄玉等材料，可组成大庚、春黎、青蟠等剑阵。
- **风雷翅**：飞遁和雷遁法宝，与鲲鹏翎羽、天凤之翎、真灵血脉相关。
- **虚天鼎**：通天灵宝级机缘，内封补天丹与乾蓝冰焰，与虚天殿、银月、小极宫相关。
- **元磁神山**：元磁神光的重要基础，后成为元合五极山材料之一。
- **玄天斩灵剑**：玄天仙果所化，蕴含毁灭法则，需强大法体支撑。
- **元合五极山**：后天玄天之宝，由五座奇山炼成。

## 器物词条字段

| 字段 | 说明 |
|---|---|
| 层级 | 法器、符宝、法宝、通天灵宝、玄天之宝、仙器等。 |
| 持有人 | 当前或关键阶段持有者。 |
| 首次出现篇章 | 用于定位剧情阶段。 |
| 材料 | 金雷竹、庚精、玄天仙藤等核心炼制来源。 |
| 能力 | 攻击、防御、飞遁、破邪、法则承载等。 |
| 结局 | 损毁、传承、升级、失落或终局保留。 |
| 克制对象 | 魔气、阴魂、法宝、阵法、法则等。 |
| 关联功法 | 青元剑诀、元磁神光、玄天炼器术等。 |
| 置信度 | 区分原著明确、公开资料整理与待复核说法。 |
