# 仙界地域

仙界篇的舞台由地域探索转向法则归属与大道冲突。韩立飞升后围绕时间法则、掌天瓶本源、天庭秩序、轮回殿反抗和道祖之争展开。

## 北寒仙域

北寒仙域是仙界篇早期主舞台，包括黑风海域、古云大陆、烛龙道、北寒仙宫和冥寒仙府。

| 地域/势力 | 类型 | 关键设定 |
|---|---|---|
| 黑风海域/乌蒙岛 | 早期海域 | 韩立成为祖神、使用无常盟面具、重启仙界修炼 |
| 烛龙道 | 北寒大宗门 | 真言化轮经、烛龙令、时间法则功法线索 |
| 北寒仙宫 | 天庭地方秩序 | 围剿百里炎、追捕韩立、冥寒仙府事件 |
| 冥寒仙府 | 仙府秘境 | 大周天星元功、玄天葫芦、金仙傀儡残躯、药园 |

## 天庭

天庭是仙界最高压迫性秩序之一，以古或今和时间道祖格局为核心。其冲突不只是统治与反抗，也涉及三千大道、三千道神大阵和混沌法则计划。

- **代表人物**：古或今、奇摩子、公输久、东方白等。
- **核心法则**：时间法则、混沌法则计划。
- **关键事件**：真言门覆灭、三千道神大阵、终局道祖大战。

## 轮回殿

轮回殿是对抗天庭的重要组织，与轮回法则、轮回殿主、南宫婉前世因果、韩立另一个时间线身份强相关。

- **代表人物**：轮回殿主、蛟三/甘九真、狐三、南宫婉、韩立。
- **关键法则**：轮回法则，与时间法则形成深层因果互补。

## 真言门

真言门是古老时间法则宗门，已被天庭覆灭，但其传承长期影响韩立仙界修炼。

| 传承 | 类型 | 作用 |
|---|---|---|
| 真言化轮经 | 时间功法 | 修炼真言宝轮、时间道纹 |
| 水衍四时诀 | 时间功法 | 凝练光阴净瓶、光阴水滴 |
| 东乙枯荣经 | 时间功法 | 草木枯荣与四时流转 |
| 断时流火集 | 时间功法 | 时间停滞类神通 |
| 幻辰宝典 | 时间炼器宝典 | 提炼幻辰沙，构建时间流速场 |

## 灰界、魔域与幽冥界

- **灰界**：灰仙、煞气、九幽域相关界面，连接百里炎、墨雨、阴丞全等线索。
- **魔域/积鳞空境**：魔主与空间法则主线，关联石穿空、石空鱼、蟹道人、紫灵。
- **幽冥界**：轮回、魂魄、刑兽体系地域，啼魂在此拥有关键身份线索。
