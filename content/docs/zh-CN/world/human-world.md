# 人界地域

人界是韩立从凡人走向修仙者的起点。它的特点是灵气不足、高阶修士稀少、资源争夺激烈，元婴修士已是一方巨擘，化神修士则普遍面临天地元气限制与飞升困境。

## 天南

天南是韩立早期和中期活动核心，由越国七派、魔道六宗、正道盟、天道盟、九国盟等势力构成。

| 地域/势力 | 类型 | 关键人物 | 设定价值 |
|---|---|---|---|
| 越国七派 | 正道宗门联盟 | 韩立、南宫婉、李化元、令狐老祖 | 血色禁地、筑基资源、魔道入侵起点 |
| 黄枫谷 | 越国七派之一 | 韩立、李化元、令狐老祖 | 韩立正式进入修仙宗门的身份起点 |
| 掩月宗 | 越国七派之一 | 南宫婉、燕如嫣、穹老怪 | 南宫婉道侣线、素女轮回功、血色禁地因果 |
| 魔道六宗 | 魔道联盟 | 王蝉、燕如嫣、云露真人 | 入侵越国，重塑天南势力格局 |
| 落云宗 | 天道盟宗门 | 韩立、慕沛灵、吕洛 | 韩立元婴期后回归天南的重要宗门身份 |

## 乱星海

乱星海是海域型修仙世界，妖兽资源丰富，散修、商盟、星宫与逆星盟并立。韩立在此完成结丹、元婴成长，并获得虚天鼎、噬金虫等关键资源。

| 地点/势力 | 关键资源 | 关联线索 |
|---|---|---|
| 天星城/星宫 | 元磁山、天星大阵、元磁神光 | 凌玉灵、天星双圣、星宫秩序 |
| 外星海 | 妖丹、妖兽材料、灵石 | 韩立猎妖积累修炼资源 |
| 虚天殿 | 虚天鼎、补天丹、乾蓝冰焰 | 玄骨、极阴、银月、血玉蜘蛛 |
| 妙音门 | 天雷竹、商贸情报 | 紫灵赠天雷竹，间接促成金雷竹飞剑体系 |
| 逆星盟 | 反星宫联盟 | 六道极圣、万天明、温天仁 |

## 极西之地

极西之地与傀儡术、大衍神君、千竹教强相关。韩立在此接触大衍诀与傀儡体系，使“神识 + 傀儡操控”成为长期战力补充。

## 草原势力

慕兰草原与天澜草原体现人界法士、图腾、圣兽信仰与部族联盟体系。天南边界大战使宗门利益、草原族群压力与外部敌人交织在一起。

## 大晋

大晋是人界最繁盛修仙文明区域，正魔十大宗门、皇族叶家、小极宫、万妖谷和散修化神并立。

| 势力 | 类型 | 关键设定 |
|---|---|---|
| 太一门 | 正道魁首 | 化神修士坐镇，大晋正道代表 |
| 天魔宗 | 魔道顶级宗门 | 紫灵线、呼老魔事件 |
| 阴罗宗 | 魔道大宗 | 鬼罗幡、封魂咒、与韩立多次结仇 |
| 小极宫 | 冰寒宗门 | 虚天鼎仿制、乾蓝冰焰、冰魄仙子线索 |
| 天符门 | 符箓宗门 | 降灵符、化灵符、符箓炼制法 |
